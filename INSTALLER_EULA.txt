2. POLÍTICA DE PRIVACIDAD LOCAL (100% OFFLINE-FIRST)
===============================================================================

Power Diagram respeta al máximo la privacidad de sus usuarios y está diseñado
bajo una arquitectura estrictamente local:

* Cero Telemetría y Cero Cuentas:
  Power Diagram no recopila información personal, credenciales, métricas de
  rendimiento, analíticas de comportamiento ni reportes automáticos de errores.
  No se requiere inicio de sesión ni conexión a internet para operar el programa.

* Almacenamiento Estrictamente Local:
  Todos sus proyectos, diagramas de bases de datos, código DBML, configuraciones
  de ventana y preferencias se guardan única y exclusivamente en su dispositivo,
  en el directorio de configuración del sistema operativo asignado a la app
  (base de datos SQLite 'erd_studio.db' y preferencias 'window-state.json').

* Sin Transmisión de Esquemas ni Scripts:
  El modelado de tablas, renderizado de diagramas, formateo de código y
  generación o parseo de scripts DDL SQL se ejecutan en su totalidad dentro
  de su máquina local. Ningún esquema ni consulta es transmitida a servidores
  externos.

* Enlaces a Sitios Externos:
  Si el usuario decide voluntariamente hacer clic en enlaces externos (como el
  repositorio oficial en GitHub), estos se abrirán en el navegador web
  predeterminado del sistema y estarán sujetos a las políticas de dicho sitio.

3. EXENCIÓN DE RESPONSABILIDAD Y USO DE SCRIPTS SQL
===============================================================================

* Verificación de Scripts SQL y Migraciones:
  Power Diagram proporciona herramientas para diseñar diagramas ERD y exportar
  código SQL para múltiples dialectos (PostgreSQL, MySQL, SQLite y SQL Server).
  El usuario es el único responsable de revisar, validar y probar exhaustivamente
  cualquier script DDL o SQL generado antes de su ejecución en bases de datos
  de producción, pruebas o desarrollo.

* Renuncia a Responsabilidad por Pérdida de Datos:
  El autor y los colaboradores no serán responsables por ninguna pérdida o
  corrupción de datos, fallas operativas, interrupciones de servicio ni

* Uso Nominativo de Marcas Comerciales:
  Los nombres, términos y logotipos relativos a PostgreSQL, MySQL, SQLite y
